# Weather-Application
Weather App 🌦️
This is a simple and user-friendly weather application that fetches and displays real-time weather information for cities around the globe. The app leverages the OpenWeatherMap API to deliver up-to-date weather details, including temperature, humidity, wind speed, and weather conditions.

#Features:
Dynamic Search:  Users can search for weather details by entering a city name. A convenient datalist ensures quick suggestions for popular cities.
Interactive Weather Display:  Displays temperature, humidity, and wind speed with corresponding weather icons for clear visualization.
Error Handling:  Notifies the user if an invalid city name is entered.
Responsive Design:  A clean and responsive layout ensures usability on various devices.

#Technologies Used:
HTML, CSS, and JavaScript for the front-end.
OpenWeatherMap API for fetching weather data dynamically.
